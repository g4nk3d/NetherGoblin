# NetherGoblin - how it is built

Files load in the order of the .toc. Everything lives in one private namespace (`ns.NG`);
the only global is `NetherGoblin` (API/Plugin.lua). Every module is `NG:Module(name)`.

## Core
- **Init.lua** - the namespace, game events (`NG:On`), the message bus (`NG:Register` /
  `NG:Fire`, every listener protected), timers, after-combat queue, the diagnostics log,
  `NG.Num / Str / Open / Call` (secret values and wrong types refused).
- **Locale.lua** / **Locales/enUS.lua** - strings (keys are the English text) and the goblin's lines.
- **Settings.lua** - every option and its default; window size can be per character.
- **Money.lua** - copper to text and back.
- **Scheduler.lua** - long work as coroutines, a time budget per frame (1 ms in combat, half
  below 30 fps, paused while the window is hidden).
- **Lifecycle.lua** - ADDON_LOADED (saved tables, migrations, `DB_READY`), PLAYER_LOGIN
  (`LOGIN`), PLAYER_LOGOUT (prices packed to CBOR).

## Data
- **Geometry.lua** - generated by the art build: where every frame piece sits, in window units.
- **Prices.lua** - the price book per auction house (ruleset). Numeric keys (item ID; gear
  `itemLevel * 1e7 + itemID`; pets `-speciesID`), one small table per item with the day's
  figures and a packed history string, market value = weighted daily lows of 14 days, item-name
  index for typed price checks, CBOR packing at logout.
- **Ledger.lua** - this character's posts / buys / bids / cancels; shopping lists; recent searches.

## AH (the auction house)
- **House.lua** - open / closed, one request queue gated on the game's message throttle
  (dropped requests resent), the game's own window hidden (alpha 0, scale 0.0001; never
  Hide(), which would close the auction house).
- **Search.lua** - browse queries (paged), one item's listings (paged; waits for the item key's
  info first; times out and still answers), results fed into Prices.
- **Scan.lua** - the quick scan: one empty browse, pages folded in through the Scheduler while
  the next page is requested; counts items, new lows, deals, changed prices; `SCAN_DONE`.
- **Buy.lua** - commodities in two clicks (quote, confirm), items by bid / buyout; every call
  that spends gold is reached only from a click.
- **Sell.lua** - sellable bag items, suggested price (undercut rule), deposit, warnings, posting
  (`PostCommodity` / `PostItem`, the pending post cached for the game's own warning dialog).
- **Owned.lua** - your auctions, undercut counting (quick, from the scan; exact, from live
  listings), cancelling.

## UI
- **Skin.lua** - the goblin look and the NetherUI theme look; roles, fonts, layers.
- **Widgets.lua** - buttons, panels, insets, text boxes, money boxes, icons, badges, the
  virtual list, settings controls.
- **Chart.lua** - the 14-day trend (lines where the client has them, dots otherwise).
- **Window.lua** - the frame art, tabs, status row, moving, corner resizing (proportions
  locked; sizes in screen pixels), positions saved.
- **Inspector.lua** - the selected item: trend, stats, deal meter, buying.
- **TabBuy / TabSell / TabAuctions (Auctions + Undercuts) / TabShopping (Shopping + History)**.
- **Popups.lua** - the Scan Complete window and the Compatibility window; Edit Mode placement.
- **Config.lua** - the settings window, slash commands, the game's AddOns options entry.

## Features
- **Tooltip.lua** - prices on item tooltips (TooltipDataProcessor; secret data left alone).
- **PriceCheck.lua** - @ / $ price checks in guild and party chat with the one-answer claim
  protocol (Docs/PROTOCOL.md).
- **Minimap.lua** - the minimap button (angle saved account-wide; button collectors may take it).
- **Compat.lua** - other auction addons: ask once (disable + reload / keep both / later).
- **Suite.lua** - NetherSuite: the descriptor (tile with Media/Banner.tga, pages, status,
  diagnostics, settings records for the hub's search; the hub only reads values), handed
  over at login or left in NetherSuite_Queue.

## API
- **Plugin.lua** - the `NetherGoblin` global (Docs/API.md).

## Messages on the bus
`DB_READY`, `LOGIN`, `LOGOUT`, `SETTING_CHANGED(key, value)`, `AH_OPEN`, `AH_CLOSED`,
`BROWSE_STARTED`, `BROWSE_RESULTS(rows, full, isNew)`, `BROWSE_FAILED`, `ITEM_RESULTS(detail)`,
`SCAN_STARTED`, `SCAN_PROGRESS(done, received)`, `SCAN_CANCELLED(why)`, `SCAN_DONE(summary)`,
`BUY_QUOTING`, `BUY_QUOTE(quote)`, `BUY_QUOTE_CLEARED`, `BUY_DONE(info)`, `BUY_FAILED(why)`,
`POSTED(info)`, `POST_FAILED(why)`, `POST_WAITING`, `SELL_PROGRESS(done, total)`,
`OWNED_UPDATED(list)`, `UNDERCUT_CHECKED(list)`, `CANCELLED(id)`, `CANCEL_FAILED(why)`,
`LEDGER_CHANGED(row)`, `LISTS_CHANGED`, `RECENT_CHANGED`, `SKIN_CHANGED(mode)`.
